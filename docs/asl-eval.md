Before = the model shipped in v1.0 (logistic regression on 2,122 `asl_now` samples, no rotation invariance). Its own random 80/20 split of that one dataset gave 96.5 %; on a held-out collection it scores 47 %.

## Model comparison (selection)

Leave-one-source-out accuracy (train on two training sources, test on the third; mirror-averaged). Same features, same augmentation, same balanced sampling for all three.

| Model | held out `asl_now` | held out `kp` | held out `cab_train` | mean | per-letter mean |
|---|---|---|---|---|---|
| Logistic regression | 70.7 % | 89.8 % | 85.8 % | **82.1 %** | 84.7 % |
| MLP 287-256-128-26 (chosen) | 76.5 % | 91.3 % | 92.7 % | **86.8 %** | 89.0 % |
| Gradient boosting (sklearn HistGB) | 71.7 % | 90.2 % | 89.2 % | **83.7 %** | 85.5 % |

The MLP wins by 3-5 points and exports to plain numpy (417 KB), so the backend stays free of sklearn/torch at inference. Gradient boosting would need an extra runtime dependency and was worse.

Feature ablation (same MLP, same protocol, mean leave-one-source-out accuracy):

| Feature set | mean |
|---|---|
| v2 base: rotation/scale/aspect normalised coordinates + orientation + 15 distances (77 features) | 84.6 % |
| + all 210 pairwise 3D distances | 86.2 % |
| **+ all 210 pairwise 2D distances (shipped, 287 features)** | **86.8 %** |
| 2D pairwise distances only (212 features) | 85.7 % |
| z set to 0 (on the 77-feature base set) | 84.7 % (no gain) |
| In this order: larger MLP (512-256, 60 epochs) / augmentation x1.6 / augmentation x0.6 / 3-seed ensemble | 86.1 / 86.7 / 86.5 / 86.8 % (no gain: the limit is data variety, not model size) |

## Why not 80 %

* **Motion letters.** J is the I handshape followed by a hook drawn in the air; from one frame it is indistinguishable from I. On the test photos 26 of 30 I are read as J (the J class absorbs the I pose because most J training frames are mid-motion I-like poses), which alone costs about 4 points. Z scores 77 %. Excluding J and Z the number is 79.6 %. Fixing this needs a temporal model and sequence data; we have no openly licensed set of isolated J/Z motions.
* **Fist-family letters.** A, S, T, M, N and E differ by where the thumb is tucked, the least reliable part of MediaPipe's landmarks: A 55 % (13 of 29 read as S), T 25 % (10 of 24 read as S). Single-frame landmarks cannot separate them better without more varied training photos.
* **Few distinct signers.** The three training collections are a handful of people each, recorded as video frames. Leave-one-source-out shows how much a new collection costs (76-93 % depending on the fold). More signers is the lever; the Record mode in the UI exists to collect them.
* **Honest measurement.** The test collection was not used for training or recipe selection (an earlier version of this project selected on it). The confidence interval is +-3 points, so 78.6 % and 80 % are statistically close; we report the measured value, not the interval end.

On a live feed the speller only commits letters held steadily, so the user-visible quality is better than the single-frame number: at the 0.6 confidence threshold used by the speller, 86.2 % of the hands that pass are correct (82 % of hands pass), and the temporal smoother removes frame-to-frame flicker.

## Reproduce

```bash
# 1. landmarks (downloads are read-only inputs; see asl-datasets.md for sources)
uv run python scripts/asl_extract.py asl_now --root /tmp/asl-now --out /tmp/asl-lm/asl_now.npz
uv run python scripts/asl_extract.py kp --root <media_pipe_keypoints_dataset> --stride 5 --out /tmp/asl-lm/kp.npz
uv run python scripts/asl_extract.py images --root <Cabana>/Train --stride 8 --pad 0 --min-side 384 --shard 0/2 --out /tmp/asl-lm/cab_train_0.npz   # and 1/2
uv run python scripts/asl_extract.py images --root <Cabana>/Test --pad 0 --min-side 384 --out /tmp/asl-lm/cab_test.npz
uv run python scripts/asl_extract.py images --root <EitanG98>/train_val --pad 0 --min-side 0 --out /tmp/asl-lm/eitan.npz
# 2. compare models, train, evaluate
uv run --with scikit-learn python scripts/train_asl.py compare --out docs/asl-compare.json
uv run --with scikit-learn python scripts/train_asl.py fit --model mlp
uv run python scripts/train_asl.py eval --model-file backend/app/models/asl_letters.npz --out docs/asl-eval-after.md
```
