# ASL fingerspelling reference illustrations

`A.svg` to `Z.svg`: the American Sign Language manual alphabet, one file per letter.

- **Source:** Wikimedia Commons, `File:Sign language A.svg` ... `File:Sign language Z.svg`
  (<https://commons.wikimedia.org/wiki/Category:ASL_letters>), based on the Gallaudet font.
- **Author:** wpclipart.com.
- **Licence:** **Public domain** (released by the author; Commons template "PD-author").
  No attribution is required; it is given here anyway.
- **Changes:** optimised with svgo (metadata and editor data removed, numbers rounded) and a
  `viewBox` added. The drawings are untouched. J and Z are drawn with their motion arrow.
- Black fill on transparent; the UI inverts them in the dark theme with a CSS filter.
