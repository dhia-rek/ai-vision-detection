# Fonts

Self-hosted variable woff2 files (Latin subset, taken from Google Fonts), SIL Open Font License 1.1.
No request leaves the page for fonts.

| `Figtree-latin.woff2` | Figtree (wght 400-700) | body | 2022 The Figtree Project Authors, https://github.com/erikdkennedy/figtree | [OFL-Figtree.txt](OFL-Figtree.txt) |
| `JetBrainsMono-latin.woff2` | JetBrains Mono (wght 400-700) | numbers, tech labels | 2020 The JetBrains Mono Project Authors, https://github.com/JetBrains/JetBrainsMono | [OFL-JetBrainsMono.txt](OFL-JetBrainsMono.txt) |

The fonts are used unmodified, so the OFL's reserved font name rule does not apply.
