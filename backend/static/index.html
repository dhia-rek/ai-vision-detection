    The story

    How it was built

    1. 01

      One camera, three ways to see

      Objects for the everyday world, expressions for faces, and ASL fingerspelling for people who sign instead of speak. Each mode is its own model, one tap away.

      3 models, 1 camera

    2. 02

      Teaching it the alphabet

      The first letter model was right 47% of the time on photos it had never seen. I rebuilt the hand features, retrained on open datasets and tested on a separate collection.

      47% → 76% letter accuracy

    3. 03

      Moving it into your browser

      It started as a Python server that received camera frames. I exported every model to run in the page with ONNX Runtime Web and MediaPipe, so frames never leave the device and hosting is free. Tests check that the browser gives the same answers as Python.

      22 / 22 parity tests

    4. 04

      What is still hard

      Reading emotion from a face is the weakest part: 25% on 700 real-world photos, where chance is 14%. Treat it as a rough guess. Letters J and Z need motion, which one frame cannot show.

      Honest numbers, measured

    Under the hood

    Objects
    YOLO11n, about 29 fps on a 6-core CPU, no GPU
    Expressions
    YuNet face finder + MobileFaceNet classifier
    Sign language
    MediaPipe hand landmarks + my letter classifier
    In the browser
    ONNX Runtime Web, Web Workers, WebGPU when available
    Behind it
    Python for training, evaluation and tests
    Hosting
    Static files on GitHub Pages, no server
